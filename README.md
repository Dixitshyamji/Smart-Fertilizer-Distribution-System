🌾 Smart Fertilizer Distribution System A robust, full-stack web platform built using React.js, Node.js, Express.js, and MySQL designed to digitize, secure, and streamline the distribution of government-subsidized fertilizers to verified farmers. The system automates land-holding quota calculations to eliminate supply-chain leakages, prevents hoarding, and provides a transparent digital booking workflow with QR token verification at godowns. 📌 Features 👨‍🌾 For Farmers Land-Based Quota Engine: Automatically calculates maximum allowed fertilizer limits (Urea, DAP, NPK) based on verified land area and crop type. Digital Reservation System: Select nearby distribution centers (godowns), schedule pickup dates, and reserve bags in real-time. Flexible Payment Methods: Options for Pay at Godown, Cash, UPI, and Online payments. QR Pickup Tokens: Generates secure booking references with encrypted QR tokens for seamless offline collection. 🏢 For Godown Managers Inventory Tracking: Real-time stock decrementing and allocation tracking. QR Token Scanner: Quick verification of farmer bookings to prevent double-dipping and fake redemptions. ⚙️ For Administrators System-Wide Analytics: Oversight of regional supply vs. demand trends. Godown & Fertilizer Management: Centralized management of godowns, active managers, and subsidization parameters. 🛠️ Tech Stack Frontend: React.js (Vite), React Router DOM, Axios, Custom Responsive CSS / CSS Modules Backend: Node.js, Express.js Database: MySQL (v8.0+) with mysql2 promise-based connection pooling Security: JSON Web Tokens (JWT) for session management, bcrypt for password hashing 🗂️ Project Directory Structure smart-fertilizer-system/ ├── client/ # React Frontend │ ├── public/ │ │ ├── favicon.ico │ │ └── index.html │ ├── src/ │ │ ├── assets/ # Static logos, images, vectors │ │ ├── components/ # Shared UI components (Navbar, ProtectedRoute) │ │ │ └── Navbar.jsx │ │ ├── pages/ # Primary view pages │ │ │ ├── FarmerLogin.jsx │ │ │ ├── BookFertilizer.jsx │ │ │ ├── FarmerDashboard.jsx │ │ │ └── AdminDashboard.jsx │ │ ├── services/ # API handlers & Axios configuration │ │ │ └── api.js │ │ ├── App.jsx # Main router configuration │ │ ├── index.css # Global application styles │ │ └── main.jsx # Entry point │ ├── .env # Frontend environment variables │ ├── .gitignore # Client gitignore rule definitions │ ├── package.json │ └── vite.config.js # Vite build tool configuration │ ├── server/ # Express.js Backend API │ ├── database/ # Relational SQL files │ │ └── schema.sql # DB schema creation & seed script │ ├── src/ │ │ ├── config/ # Database connection setup │ │ │ └── db.js │ │ ├── controllers/ # Business logic & request handlers │ │ │ ├── authController.js │ │ │ └── bookingController.js │ │ ├── middleware/ # JWT verification & role authorization │ │ │ └── authMiddleware.js │ │ ├── routes/ # Express route definitions │ │ │ ├── authRoutes.js │ │ │ └── bookingRoutes.js │ │ └── server.js # Server initialization & entry point │ ├── .env # DB credentials, JWT secret, server port │ ├── .gitignore # Server gitignore rule definitions │ └── package.json │ └── README.md # Complete project documentation
